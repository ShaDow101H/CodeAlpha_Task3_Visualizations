# SuperStore Sales & Profit Dashboard

I built this dashboard in Power BI for Task 3 (Data Visualization) of the CodeAlpha Data Analytics internship. It uses the Sample Superstore dataset to visualize sales and profit performance.

## What's in the dashboard

It has 3 pages:

**Page 1** — overall numbers: Total Sales, Total Profit, Profit Margin % and Total Orders cards.

**Page 2** — category-level analysis. A chart comparing sales and profit by Category, plus a profit chart by Sub-Category. You can see that some sub-categories sell well but barely make profit, or even lose money.

**Page 3** — a closer look at region, discount and city:
- Profit margin by region
- A scatter chart showing the relationship between discount and profit (colored by category)
- A sales/profit combo chart by discount group
- Sales volume by city

## Key takeaways

High sales don't always mean high profit — some sub-categories actually show the opposite. As discounts go up, profit tends to drop, sometimes going negative. There's also a noticeable gap in margin between regions, so applying the same strategy everywhere probably isn't a good idea.

## Tool used

Power BI Desktop. You'll need Power BI Desktop to open the file (free download from Microsoft).

## What could be added

Right now there are no slicers — adding a filter by Region or Category would make it more interactive. Also, a short text box on each page explaining the insight would help someone understand it without needing a walkthrough. Planning to add these in a future version.
